## 1. 最初に確認すること

この環境は、旧システムの池袋データを使った**画面・操作確認専用**です。本番業務には使用しません。

- 公開HP: <https://salon.c-platinum.com/ikebukuro>
- 管理画面: <https://salon.c-platinum.com/admin/login>
- 管理画面のメールアドレスとパスワードは、担当者から別に受け取ってください。
- データの基準日時は **2026年7月21日 12:07** です。それより後に旧システムへ登録した内容は表示されません。

### 表示される印の意味

| 表示       | 意味                                                       |
| ---------- | ---------------------------------------------------------- |
| `[確認用]` | 旧システムから確認用にコピーし、個人情報を匿名化したデータ |
| `[UAT]`    | 操作テストのために新しく作成するデータ                     |

`[確認用]` は不具合ではありません。実顧客と間違えないための印です。

### やってはいけないこと

- 実在するお客様の氏名、電話番号、メールアドレス、住所を入力しない。
- 実際の予約、会計、ポイント処理として使用しない。
- 電話、LINE、SMS、メールの実送信や、実カードでの決済を試さない。
- `[確認用]` の既存データを変更・削除しない。
- 「保存」「削除」「修正可能にする」「状態変更」「予約確定」は押さない。
- この環境で入力した内容を本番データとして扱わない。最終移行時に消去されます。

### 今回の合否対象外

実顧客の個人情報、ポイント残高・履歴、NG設定、チャット、精算、予約変更の完全履歴、非公開画像は最終移行前のため、今回の現場確認では合否を付けません。

## 2. 記録方法

各項目に `○`、`△`、`×` のいずれかを記入します。

| 記号 | 判定                                                   |
| ---- | ------------------------------------------------------ |
| ○    | 問題なく確認できた                                     |
| △    | 表示はできたが、旧システムとの違い・不明点がある       |
| ×    | エラー、表示されない、保存できない、内容が明らかに違う |

`△` または `×` の場合は、画面名・URL・確認時刻・対象IDを「不具合メモ」に記録してください。お客様の氏名、電話番号、メールアドレスは記録しません。

## 5. 操作範囲と重点確認（目安 5分）

### 現場確認で押してよい操作

- 日付変更
- タイムライン／一覧などの表示切替
- 既存データの詳細を開く・閉じる
- ページ移動、再読込
- 明らかに閲覧専用の検索

### 現場確認では押さない操作

- 保存、削除、停止、有効／無効の切替
- 修正可能にする、予約状態の変更、キャンセル確定
- 新規予約、新規顧客、新規キャストの確定
- LINE通知、メール、入室通知、決済
- 全店舗への同期

書込み動作は技術担当が確認済みです。現場の方は再実施せず、表示内容と業務の流れを確認します。書込み確認が別途必要な場合は、担当者立会いのもと、名前・メモの先頭へ `[UAT]` を付けた専用データだけを使用します。

### 重点確認

次のケースを見つけた場合は、旧システムと特に丁寧に比較します。

- 深夜0時を越える予約・出勤
- 24:00以降の時刻表記
- 複数コースまたは複数オプションの予約
- キャンセル済み・修正可能・仮予約など、確定以外の予約
- 出勤予定がない日、または同じキャストに複数の出勤枠がある日
- 画像が表示されない、別キャストの画像に見えるケース

違いがある場合は無理に正しいと判断せず、`△` または `×` としてください。
