# 2026年9月5日 キャスト・出勤表の再修正

対象: [#282 キャスト](https://app.notion.com/p/3ccdda8d8bde80b19a27f2cd7dd8a2d1)、[#283 出勤表](https://app.notion.com/p/3ccdda8d8bde803fa9b6eeddcb522958)。ユーザーが追加した指摘を含む。反映先は https://salon.c-platinum.com/admin/ を提供する `salon-preview-system` のみ。

## 修正内容

- 新規キャストはフォーム・APIとも仮登録。週間表は在籍だけを集計・表示。キャスト一覧は在籍を初期表示し、仮登録・在籍・退店の3状態で絞り込む。
- 一覧の操作部・カード画像・週間表の行を縮める。本人確認の警告は「身分証 未確認」「住民票 未確認」を一覧に表示する。
- 手取りUPをお客様向け指名料と別の金額マスタへ分離。管理 > 設定 > 指名料金設定 > キャスト手取UPで、フリー・パネル・おすすめP・本指名を個別に追加・編集・停止できる。キャストの基本情報からそれぞれ選択する。
- 既存の手取りUP選択は同額の内部マスタへ移行し、お客様の料金・分配額とキャストのその他情報を保持。オーダー入力中の計算、予約保存時の計算の双方で4種類を個別に適用する。手取りUPをお客様へ追加請求しない。
- ネット予約の本指名料金は店舗の本指名マスタを参照する。未設定のキャストの本指名が0円になる不具合を解消。店舗に料金が未登録なら予約を受け付けずエラーを表示する。
- テンプレート保存と個別キャスト概要からの出勤保存に店舗IDを明示。保存エラー時は入力を保持し、読込失敗時は既存テンプレートの上書きを防ぐ。時間の二重表記を除去。
- 出勤保存を待ち、成功後も編集画面を開いたままにする。変更した日だけ保存し、未入力へ戻す操作も反映。媒体用テキストと備考を別々に保存する。
- 編集ヘッダーにキャスト名・保存・前週/翌週を固定し、下部にも移動・保存・閉じるを配置。編集の途中で閉じる場合とブラウザの再読込・離脱時は未保存警告を表示する。
- 4週間は日付を選んで1日ずつ入力するカレンダー形式へ変更。保存済みテンプレートを選んで日付をクリックすると一括入力できる。週移動時・親画面の再取得時も未保存内容を保持し、キャスト切替では分離する。
